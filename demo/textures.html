材质贴图 · Material Textures

木板、原木、石料、矿石的 CSS 贴图类，一个 class 换一张 16×16 像素材质。
点击任意色卡可在「单块铺满」与「32px 平铺」之间切换，用来检查接缝。

木板 · Wood Planks

11 种

主建筑材质。每张都是可无缝平铺的 16×16 贴图，色卡用 .mc-tex--oak_planks 这类类名引用， 3D 方块则直接复用技能里的 createMinecraftCube()。

原木 · Logs

6 面 / 侧面

原木需要区分侧面与顶面：侧面做四个立面，顶面与底面单独一张，和技能里的分面贴图规则一致。

石料 · Stone & Building

11 张

石头、圆石、石砖到砂岩、石英、海晶石，纹理都带明显的像素接缝，平铺模式下最容易看出问题。

自然 · Natural

7 张

草方块拆成顶面与侧面；泥土、沙子、沙砾、泥巴、苔藓块可以直接铺满整块。

矿石 · Ores

8 张

矿石色卡保留了技能里的发光色，3D 方块可以叠加 anim-glow 呼吸发光。

CSS 用法 · How to use

1 · 贴图类

/* 基础：铺满 + 像素化 */
.mc-tex {
  background-size: 100% 100%;
  background-repeat: no-repeat;
  image-rendering: pixelated;
}

/* 换材质只写一行 */
.mc-tex--oak_planks {
  background-image: url("../assets/block-textures/橡木木板.png");
}

2 · 平铺检查

/* 16×16 贴图按 32px 重复 */
.mc-tex.is-tiled {
  background-size: 32px 32px;
  background-repeat: repeat;
}

/* 页面里 */
<div class="mc-tex mc-tex--stone_bricks"></div>

放大后用 is-tiled 看四条边是否能接上；接不上说明贴图本身不可平铺。

3 · 3D 方块

/* 贴图目录：默认 ../mc中文素材/ */
window.MC_TEX_PATH = "assets/block-textures/";

const stage = createMinecraftCube(
  "oak_planks", { size: "md" }
);
bindClickFlip(stage);

技能包里的 blocks.js 会读取 MC_TEX_PATH，把贴图目录指到页面的贴图目录；本页用 ../assets/block-textures/。
