# 材质搭配方案

侧栏、面板、卡片这类大面积 UI 的背景贴图怎么挑，本文给出 6 套已配好的组合。全部素材来自 `assets/block-textures/`（16×16 原版贴图），每张都标了中文文件名、对应 CSS 材质类（见 `references/asset-catalog.md`）和实测平均色。

可视化预览见 `demo/palette.html`：每套方案都渲染了模拟侧栏、激活态、内容区标题条和三张贴图清单，另附橡木与深色橡木的平铺对照。

## 通用规则

1. **底图要暗、纹理要匀**：大面积平铺选平均亮度中等偏暗、纹理横向/砖缝规整的贴图；木纹（橡木、白桦）横向条纹密，平铺到侧栏容易显花，不推荐做整面底图。
2. **一套方案最多两种贴图**：底图 + 强调（标题条 / 激活态 / 描边），强调贴图只用一处。
3. **压暗靠面板底色，不靠滤镜**：`background-color: <深色>; background-blend-mode: multiply;` 配合 32px 平铺。
4. **文字色**：浅贴图（砂岩、石英）用 `#241d16` 深色文字；其余用 `#e8e2d4` 浅色文字 + `1px 1px 0 #000` 投影。
5. 每张方案卡里的 `background-size: 32px 32px; image-rendering: pixelated;` 保持不变，只换 `background-image`。

## 方案 1 · 冷灰石砖（推荐默认）

| 部位 | 贴图 | 材质类 | 平均色 |
| --- | --- | --- | --- |
| 侧栏底图 | 石砖.png | `.mc-tex--stone_bricks` | `#7a797a` |
| 标题条 / 激活态 | 苔石砖.png | `.mc-tex--mossy_stone_bricks` | `#737969` |
| 强调点缀 | 绿宝石矿石.png | `.mc-tex--emerald_ore` | `#6c8873` |

灰底自带工具感，苔石砖的一点苔绿刚好呼应页面的草绿强调色，不会和导航高亮打架。适合做工具型页面的主侧栏。

```css
.sidebar {
  background-color: #2a2620;
  background-image: url("../assets/block-textures/石砖.png");
  background-size: 32px 32px;
  background-blend-mode: multiply;
}
.sidebar .active {
  background-image: url("../assets/block-textures/苔石砖.png");
  background-size: 32px 32px;
  background-blend-mode: multiply;
}
```

## 为什么橡木木板不适合侧栏

橡木木板（`.mc-tex--oak_planks`）平均色 `#a2824e`：亮度偏高、横向板缝每 4px 一条，大面积平铺后条纹密集，文字压上去对比度也不够。它更适合做**内容卡片底图**（小面积）或 3D 方块六面贴图，而不是整面侧栏。如果一定要用木系底图，选平均色更暗的深色橡木（方案 2）或换成石系（方案 1）。

## 验收清单

替换侧栏贴图后逐项核对：

- 平铺 32px、像素化无缩放模糊，接缝处无亮线。
- 标题条 / 激活态只出现一种强调贴图，且和底图色相有明显区分。
- 浅色方案文字已改深色，深色方案文字带 1px 黑投影。
- 面板描边仍是 `#120e0a` 3px + inset 高光，不要跟着贴图换色。
